# 圣遗物 · A Relíquia

改编自埃萨·德·凯罗斯同名小说的中文文学游戏。制作者：周宁。

电脑端使用鼠标和键盘，手机端横屏游玩；从绿色书封进入第一至第七章。

## 本地运行

需要 Node.js。运行 `npm run dev` 启动本地预览；`npm run build` 生成 `dist/`。

`playtest.html` 提供完整新试玩入口，`playtest.html?start=jerusalem` 从耶路撒冷开始。新试玩会先备份当前浏览器剧情存档并保留设置。

第四章独立重玩入口：`chapter4.html?preview=1&fresh=1`。省略 `fresh=1` 会恢复该测试存档，已通关时会接续第五章；测试进度与正式阅读进度分开。

## 素材说明

原作文本依据 IN-CM 2021 年校勘本。游戏插画与人物美术由 AI 生成并按项目参照修订。Three.js 的许可证随 vendor 目录保留。

营地鼾声剪辑自 jianchri 的 [snore.wav](https://freesound.org/people/jianchri/sounds/413721/)，CC0 授权；经过截取、滤波、淡入淡出及音量处理。

研究资料、原作文件与美术母版不包含在本仓库中。
